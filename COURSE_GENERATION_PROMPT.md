# 📚 Промпт для генерации тестового курса

## 🎯 Инструкция для нейросети

Создай детализированный курс с полным контентом, тестами и викторинами в формате, готовом для загрузки в базу данных PostgreSQL.

---

## 📋 Требования к курсу

### Общие параметры:
- **Название курса:** "Основы Python для начинающих"
- **Описание:** Полноценный курс для освоения Python с нуля до уверенного junior уровня
- **Статус:** `active` (активный)
- **Бесплатный:** `true` (демо-курс)
- **Цена:** `0` Stars
- **Длительность:** 4-6 недель при 3-5 часах в неделю

### Структура курса:

**5 тем (topics)**, в каждой теме:
- **4-6 уроков (lessons)** с полным текстовым контентом (500-1000 слов каждый)
- **2-3 викторины (quizzes)** - быстрые проверки понимания (1-3 вопроса)
- **1 тест (test)** в конце темы - финальная проверка (5-10 вопросов)

**Итого в курсе:**
- ~25 уроков с контентом
- ~12 викторин
- ~5 финальных тестов
- **Всего ~40-50 элементов контента**

## 🎨 Примеры контента

### Пример урока (полный):

```markdown
# Переменные и типы данных в Python

Python — это язык с динамической типизацией. Это значит, что вам не нужно заранее объявлять тип переменной - Python определит его автоматически.

## Создание переменных

Переменная создаётся простым присваиванием значения:

```python
name = "Алексей"
age = 25
height = 1.75
is_student = True
```

В этом примере мы создали 4 переменные разных типов:
- `name` - строка (str)
- `age` - целое число (int)
- `height` - число с плавающей точкой (float)
- `is_student` - булево значение (bool)

## Базовые типы данных

### 1. Числа (int и float)

```python
# Целые числа
count = 100
temperature = -15

# Дробные числа
pi = 3.14159
price = 99.99

# Арифметические операции
sum_result = 10 + 5        # 15
difference = 10 - 5        # 5
product = 10 * 5           # 50
division = 10 / 3          # 3.333...
integer_division = 10 // 3 # 3
remainder = 10 % 3         # 1
power = 2 ** 10            # 1024
```

### 2. Строки (str)

```python
# Создание строк
single_quotes = 'Hello'
double_quotes = "World"
multiline = """Это
многострочная
строка"""

# Операции со строками
full_name = "Иван" + " " + "Иванов"  # Конкатенация
repeated = "Hi! " * 3                 # "Hi! Hi! Hi! "
length = len("Python")                # 6
```

### 3. Булевы значения (bool)

```python
is_valid = True
is_empty = False

# Логические операции
result1 = True and False  # False
result2 = True or False   # True
result3 = not True        # False
```

## Проверка типа

Используйте функцию `type()` для проверки типа переменной:

```python
x = 42
print(type(x))  # <class 'int'>

y = "Hello"
print(type(y))  # <class 'str'>
```

## Преобразование типов

Python позволяет конвертировать данные между типами:

```python
# В строку
str(100)      # "100"
str(3.14)     # "3.14"

# В число
int("50")     # 50
float("3.14") # 3.14
int(3.99)     # 3 (отбрасывает дробную часть)

# В булево
bool(1)       # True
bool(0)       # False
bool("")      # False
bool("text")  # True
```

## Правила именования переменных

✅ **Правильно:**
- `user_name`
- `total_price`
- `count1`, `count2`

❌ **Неправильно:**
- `2count` (начинается с цифры)
- `user-name` (дефис)
- `class` (зарезервированное слово)

## Резюме

- Python автоматически определяет тип переменной
- Основные типы: int, float, str, bool
- Используйте `type()` для проверки типа
- Функции `int()`, `float()`, `str()` конвертируют типы
- Имена переменных должны быть понятными и следовать конвенциям

В следующем уроке мы изучим операции с числами и строками подробнее.
